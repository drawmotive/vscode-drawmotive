# VS Code DrawMotive

This public extension hosts the public Editor SDK and Editor UI. Keep file
identity, filesystem writes and external reload decisions in the extension;
keep document semantics and drawing controls in their public packages. Do not
import private site or synchronization code.

- Write repository-authored documentation, comments, diagnostics, interface text,
  tests and instructions in English. Preserve intentional multilingual fixture
  data and upstream license notices.
- Use npm and committed package-lock.json files. Registry locks describe actual
  published packages; explicit candidate commands must not rewrite them.
- Use the serial test commands in package.json. Verify changed UI with the real
  packaged canvas and actual VS Code host when available.
- Preserve packaged SDK modules, Workers, styles and third-party notices.
- Release helpers in .release are generated by the integration repository; change
  their shared authority there and project the result.
