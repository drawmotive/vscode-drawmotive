# Security reporting

This policy covers the VS Code extension, its local asset-serving integration
and bundled public Editor runtime. Include the extension/Editor/VS Code
versions, OS, desktop or remote-host setup, a minimal reproduction and expected
impact. Remove secrets and unrelated private diagram data from reports.

GitHub private vulnerability reporting is enabled. Use
[Report a vulnerability](https://github.com/drawmotive/vscode-drawmotive/security/advisories/new)
to submit a private report. Do not post exploit details publicly.

Use the [public issue tracker](https://github.com/drawmotive/vscode-drawmotive/issues)
for ordinary bugs and support questions without sensitive details.
